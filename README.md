# Yalla Kora Iraq

مستودع لتحديث جدول المباريات تلقائياً باستخدام GitHub Actions.

## ما يفعله
- يشغّل التحديث كل 30 دقيقة، مع إمكانية التشغيل اليدوي.
- يجلب صفحة المباريات من المصدر المحدد ويستخرج أسماء الفريقين، الشعارين، التوقيت، النتيجة، الحالة، القناة، المعلق، الدوري ورابط المباراة عندما تكون موجودة.
- يحفظ النتائج في `matches.json` بصيغة JSON مناسبة للاستهلاك من تطبيق HTML.
- إذا تعذر جلب المصدر أو لم يجد مباريات، يفشل التشغيل ولا يستبدل البيانات السابقة ببيانات فارغة.

## تفعيل المستودع
1. ارفع الملفات إلى مستودع `yalla-kora-iraq` مع الحفاظ على المسارات.
2. افتح **Actions** وفعّل workflows إذا ظهر زر التفعيل.
3. شغّل `Update matches` يدوياً أول مرة، ثم راجع سجل التشغيل.
4. ملف البيانات بعد نجاح التشغيل: `matches.json`.

رابط JSON الخام بعد رفع الملفات وتشغيل ناجح:
`https://raw.githubusercontent.com/pesmobilebysmwbayl8-netizen/yalla-kora-iraq/main/matches.json`

## ملاحظات
- يعتمد الاستخراج على بنية صفحة المصدر؛ إذا تغيّرت، افحص سجل Actions وعدّل المحددات في `scripts/update_matches.py`.
- لا توجد ضمانة بأن المصدر متاح دائماً أو يسمح بالطلبات الآلية.
- هذا الإصدار لا يغيّر تصميم تطبيق HTML ولا يكتب إلى Supabase. ربط التطبيق بملف JSON وربط Supabase خطوة لاحقة بعد التأكد من نجاح التحديث.
- لا تضع مفاتيح سرية في المستودع.
